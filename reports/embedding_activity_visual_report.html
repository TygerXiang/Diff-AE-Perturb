1. 模型与 Activity 模块

PerturbDiff 使用表达向量编码器得到语义 latent z_sem，为每个 perturbation/sgRNA 学习 latent delta embedding，再用条件 DDIM denoiser 从控制细胞生成目标扰动表达。

基础条件路径

SemanticEncoder 将 x0 编码为 z_sem；PerturbationModule 为每个 sgRNA 提供 delta_base。推理时从控制细胞 latent 出发，构造 z_cf = z_sem - source_delta + target_delta，再传入 DDIM denoiser。

因此 perturbation embedding 本身既有长度（强度）也有方向（target identity / response direction）。

Activity conditioning 实现

activity 模块打开后，模型先把 sgRNA 特征转换为非负 strength。在 predicted 模式中，GuideStrengthEncoder 用 Table S8 的 genome input 与 sgRNA input 两通道 one-hot 序列，经 CNN 回归 strength；在 direct 模式中直接读取 activity 标量。

GeneralizedSigmoid 为每个 target 学习 beta/bias，将 strength 映射为 target-specific activity_value。本次 explicit_only_200ep 中，activity_value 被线性投影成 16 维 activity_embedding 作为 denoiser 额外输入，而没有启用 delta scaling。

6. 综合解读

activity 模块更明显地改善了均值型/方向型表达预测指标：MSE 降低，PCC_delta 大幅提高；但分布距离指标并未同步改善，说明 explicit activity condition 可能使平均 perturbation direction 更准确，却未完全改善细胞分布层面的生成匹配。

embedding 既编码 activity 强度，也编码 target identity。norm 与 activity 相关，而方向空间中同 gene sgRNA 明显聚集。sequence 层面，PAM distance 与 rG:dT 两个强 activity determinant 在 embedding_s 中能看到同向模式；较弱的 GC、neighbor G 和 first G 特征在当前训练子集中不稳定。
